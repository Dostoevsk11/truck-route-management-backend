# Transportation Management Backend

Backend system for managing fleet operations, drivers, routes, trips,
and vehicle tracking for a road transportation company.

The project focuses on backend architecture and domain modeling using
Java 26 and Spring Boot.

## Tech Stack

- Java 26
- Spring Boot
- Spring Data JPA
- MySQL
- Flyway
- Spring Security
- JWT
- OpenAPI / Swagger
- Maven

## Architecture

The system follows a modular architecture based on:

- Domain-Driven Design (DDD)
- Clean Architecture
- CQRS
- Domain Events
- Integration Events
- Anti-Corruption Layer (ACL)
- Repository Pattern
- Dependency Inversion
- Value Objects
- Aggregate Roots
- Bounded Contexts
